# Заявки в Google Таблицу

Обе формы сайта пишут заявки в одну Google Таблицу, каждая на свой лист:

| Форма | Лист |
|---|---|
| `/form` — анкета для рекламы | **Анкеты (реклама)** |
| `/apply` — заявка на консультацию | **Заявки с сайта** |

Сайт отправляет заявку на свой сервер (`src/lib/leads.ts`), а тот передаёт её скрипту таблицы (`leads.gs`).
Адрес скрипта и секретный токен хранятся в переменных окружения, в коде их нет.

## Подключение (один раз, ~5 минут)

1. Создайте Google Таблицу (sheets.new), назовите, например, «Saffet — заявки».
2. **Расширения → Apps Script**. Удалите всё в `Код.gs` и вставьте содержимое `leads.gs`. Сохраните (Cmd + S).
3. Вверху выберите функцию **`setup`** → **Выполнить**. Google попросит доступ к таблице: «Проверить разрешения» → ваш аккаунт → «Дополнительно» → «Перейти в проект (небезопасно)» → «Разрешить».
   Скрипт создаст и оформит оба листа. Внизу, в «Журнале выполнения», появится строка `SHEETS_TOKEN=…` — скопируйте значение.
4. **Начать развертывание → Новое развертывание** → тип «Веб-приложение»:
   - Выполнять как: **Я**
   - У кого есть доступ: **Все**

   «Начать развертывание» → скопируйте **URL веб-приложения** (заканчивается на `/exec`).
5. Вставьте оба значения:
   - **локально** — в файл `website/.env.local` (образец в `.env.example`), затем перезапустите `npm run dev`;
   - **на Vercel** — Project → Settings → Environment Variables: `SHEETS_WEBHOOK_URL` и `SHEETS_TOKEN`, затем Redeploy.

## Как пользоваться

- Новые заявки появляются внизу листа со статусом **Новая**.
- Статус меняется из выпадающего списка: Новая → В работе → Связались → Поступил / Отказ, у каждого свой цвет.
- Фильтр в шапке уже включён — можно смотреть, например, только «Новые».
- Меню **Saffet → Оформить листы** заново применяет оформление (если что-то сбилось). Данные не трогает.

## Если поменяли `leads.gs`

Apps Script → **Начать развертывание → Управление развертываниями** → карандаш → Версия: «Новая версия» → «Начать развертывание». URL остаётся тем же.
