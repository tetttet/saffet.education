# Фото обложек вузов

Положите фото в `public/universities/` с именем из правой колонки. Подходят .jpg, .jpeg, .png, .webp; лучше горизонтальное, примерно 1200×500 px.
Вузы без фото показываются с генерированной обложкой. Новое фото появится после обновления страницы в `npm run dev` или после пересборки (`npm run build`).
